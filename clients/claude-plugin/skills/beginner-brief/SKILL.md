# Brief for non-specialists

Follow `cop31-protocol`. Answer in the user's language. Audience: smart, in a hurry, not a specialist. No
unexplained acronym (`glossaire` first).

## Output (readable in 3 minutes)
1. **What it is about** — 3 sentences, no jargon, with the reference text cited.
2. **Why it is hard** — the real conflict (money, historical responsibility, sovereignty, timing…).
3. **Who wants what** — 3–5 lines: EU, main blocs (G77/China, AOSIS, LMDC, Arab Group…), with the source.
4. **What the EU wants** — quoted (Council conclusions, NDC).
5. **Useful figures** — 1 to 3, sourced (`donnees` or reports).
6. **3 substantive questions to ask** — to bring the discussion back to substance when it gets lost in procedure
   (e.g. "Concretely, what effect on 2035 emissions?", "Who pays, and under which text?").
7. **Language traps** — wording not to over-interpret (urges ≠ shall, "take note", brackets).

Always end with the sources (level + link). If something is not found in the corpus, say so.
